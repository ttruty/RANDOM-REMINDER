How background alerts work here

This app is installed as a Progressive Web App with no backend server — so it relies on the Periodic Background Sync API to wake up and check for due reminders while closed. That API is currently supported only on Chrome/Edge for Android, and only after you've added this app to your home screen and used it a bit (the browser decides the actual wake-up frequency, so timing while closed is best-effort, not exact).

You don't appear to be on Android Chrome/Edge right now — background alerts while the app is fully closed likely won't fire on this browser. Reminders will still work reliably whenever the app is open in a tab or in the foreground.

Tip: use the browser menu → "Add to Home screen" / "Install app" to install it — background alerts are much more reliable once installed.

For guaranteed exact-time alerts

Browsers intentionally limit background wake-ups for battery/privacy reasons. If you need alerts that fire at a precise time even when the app has been closed for days, that requires either a real push server (Web Push) or a native app build (e.g. via Capacitor) using true OS-level scheduled notifications — outside the scope of this static, no-backend deployment.
